# 班級作業缺交系統與雲端一番賞

導師用手機記錄作業缺交座號，同步投影到大電視；另有「雲端一番賞」抽籤頁，抽籤券由導師依 ClassDojo 點數手動發放。

| 頁面 | 檔名 | 用途 |
| --- | --- | --- |
| 記錄頁 | `index.html` | 手機點座號記錄缺交、補交，管理作業與投影順序 |
| 設定頁 | `settings.html` | 存取碼、名單匯入、在籍狀態、發券、籤池重設、抽籤紀錄 |
| 投影頁 | `board.html` | 大電視顯示最多 5 項作業的缺交座號，每 10 秒更新 |
| 抽籤頁 | `lottery.html` | 夜空主題一番賞，含動畫、背景音樂與合成音效 |

技術：純 HTML、CSS、JavaScript（GitHub Pages）＋ Google Apps Script（GAS）＋ Google 試算表。不需要 `npm install`。

## 一、先讀：安全與個資提醒

1. **兩組存取碼，只放在 GAS 的「指令碼屬性」**。程式碼、`config.js`、GitHub 都不會出現存取碼。
   | 屬性名稱 | 稱呼 | 能做什麼 | 輸入在哪裡 |
   | --- | --- | --- | --- |
   | `ACCESS_CODE` | 導師碼 | 全部功能：記錄缺交、名單、發券、重設籤池、看紀錄 | 只在導師自己的手機或電腦 |
   | `DISPLAY_CODE` | 教室碼 | 只能看投影頁、抽籤頁，以及按「抽」 | 班級電腦（學生可能碰到的裝置） |

   權限由後端判斷：教室碼呼叫導師功能時一律回 `FORBIDDEN`，就算學生知道記錄頁、設定頁的網址也改不了資料、發不了券。教室碼仍可按「抽」，但必須有券，而券只有導師碼能發。
2. **GitHub Pages 是公開的純靜態空間，無法保護任何私密金鑰或環境變數**。所以前端只放公開資訊（GAS 網址、音樂設定），真正的保護靠 GAS 端驗證存取碼。
3. **GAS 部署為「執行身分：我；存取權：任何人」的風險**：任何拿到網址的人都能呼叫這個 Web App，而它是用「導師的身分」讀寫試算表。這個組合本身有權限升級風險，本系統的防線是：
   - 每個 API（包含讀取）都先比對存取碼，錯了回 `UNAUTHORIZED`，不回傳任何資料。
   - 所有請求用 POST，存取碼不會出現在網址或瀏覽紀錄。
   - `appsscript.json` 只宣告 `spreadsheets.currentonly` 權限（只能動「這一份」試算表，不能碰雲端硬碟其他檔案）。
   - 建議：兩組存取碼都至少 12 個字元、混合英數，而且不能相同；學期中若懷疑外洩，到指令碼屬性改掉即可立即失效（各裝置需重新輸入）。
   - 不要在學生面前輸入導師碼；在班級電腦臨時要用導師功能時，取消勾選「記住在這台裝置」，關閉分頁就會登出。
   - 為什麼不用「只有我」：電視、手機的瀏覽器需要不登入也能呼叫 API，「只有我」會讓投影頁無法讀取。
4. **個資**：試算表與畫面只有座號（可選填班級代號），不存姓名、身分證字號。CSV 裡的姓名欄會在瀏覽器端直接丟棄，不會上傳；後端也會拒絕任何多餘欄位。
5. **資料委外與保存期限**：Google 試算表屬國外雲端服務，存放學生座號與缺交紀錄屬資料委外處理，必要時先向學校資安窗口報備。建議保存到學期末：學期結束時刪除「缺交」「作業」工作表的資料列，畢業時刪除整份試算表。
6. **試算表權限**：試算表不要分享給其他人，保持「僅限導師帳號」。

## 二、部署步驟（第一次設定，約 20 分鐘）

### 步驟 1：建立試算表
1. 到 Google 雲端硬碟新增一份 Google 試算表，命名例如「班級作業系統」。
2. 不要分享給任何人。

### 步驟 2：貼上後端程式
1. 在試算表選單點「擴充功能 → Apps Script」。
2. 把預設的 `Code.gs` 內容全部刪掉，貼上本專案 `gas/Code.gs` 的全部內容，按儲存。
3. 設定權限清單（為什麼：避免 Google 自動要求「雲端硬碟全部檔案」這種過大的權限）：
   - 左側「專案設定（齒輪）」→ 勾選「在編輯器中顯示『appsscript.json』資訊清單檔案」。
   - 回到「編輯器」，打開 `appsscript.json`，把內容換成本專案 `gas/appsscript.json`，儲存。

### 步驟 3：設定兩組存取碼
1. 左側「專案設定（齒輪）」→ 最下方「指令碼屬性」→「新增指令碼屬性」。
2. 新增兩個屬性（值都由您自己決定，請自行記好，不要寫在任何檔案裡）：
   - `ACCESS_CODE`：導師碼。
   - `DISPLAY_CODE`：教室碼，必須和導師碼不同。
3. 儲存。
4. 如果先不設 `DISPLAY_CODE`，系統一樣能用，只是班級電腦也得輸入導師碼（就會有學生能改資料的風險）。

### 步驟 4：執行 setup() 並授權
1. 回到編輯器，上方函式選單選 `setup`，按「執行」。
2. 第一次會要求授權：選您的帳號 →（若出現「Google 尚未驗證這個應用程式」）點「進階 → 前往（不安全）」→ 允許。這是因為程式是您自己寫的、沒有送 Google 審核，屬正常現象。授權內容應只有「查看及管理這個應用程式所在的試算表」。
3. 執行完成後，試算表會多出 7 張工作表：名單、作業、缺交、抽籤券、籤池、卡片、抽籤紀錄。
4. 若出現「尚未設定導師碼」錯誤，代表步驟 3 沒有完成；若出現「教室碼不可以和導師碼相同」，請把 `DISPLAY_CODE` 改成不同的值。
5. 再執行一次 `setup()` 也不會覆蓋既有資料。

### 步驟 5：部署為網頁應用程式
1. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」。
2. 執行身分：**我**；誰可以存取：**任何人**（風險說明見第一節第 3 點）。
3. 按「部署」，複製「網頁應用程式網址」（以 `/exec` 結尾）。
4. 之後若修改 `Code.gs`，要用「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選『新版本』→ 部署」，網址才不會變。

### 步驟 6：填寫 config.js
打開 `config.js`，把網址貼到 `GAS_URL`：

```js
GAS_URL: 'https://script.google.com/macros/s/……/exec',
```

`config.js` 只能放這三項：`GAS_URL`、`MUSIC_SOURCE`、`YOUTUBE_VIDEO_ID`。不要放存取碼。

### 步驟 7：啟用 GitHub Pages
1. 在 GitHub 建立 repository，上傳本專案所有檔案（`.gitignore` 已排除機敏檔與 mp3）。
2. 上傳前先在終端機執行 `git status`，確認沒有 `.env`、真實名單 CSV 或 mp3。
3. Repository → Settings → Pages → Source 選「Deploy from a branch」，分支選 `main`、資料夾 `/ (root)`，儲存。
4. 約 1 分鐘後會得到網址，例如 `https://帳號.github.io/repo名稱/`。

### 步驟 8：輸入存取碼並測試
1. **導師的手機**：打開 `https://…/settings.html`，輸入**導師碼**，保持勾選「記住在這台裝置」，按「儲存並測試連線」，看到「連線成功：導師碼」即完成。
2. **班級電腦**：打開 `https://…/board.html`（或 `lottery.html`），在跳出的視窗輸入**教室碼**，保持勾選「記住在這台裝置」。之後投影頁與抽籤頁都不用再輸入。
3. 班級電腦**不要**記住導師碼。真的需要在班級電腦上用記錄頁或設定頁時，輸入導師碼時取消勾選「記住在這台裝置」，用完關閉分頁即登出，電腦上仍只留著教室碼。
4. 匯入名單：下載 `template-roster.csv`，用 Excel 填好座號（可不填班級代號）後另存 CSV，再到設定頁匯入。

## 三、日常使用

- **記錄缺交**：手機開 `index.html` → 選作業（或新增）→ 點座號變紅＝缺交 → 按「儲存」。
- **補交**：按「補交模式」→ 點紅色座號 → 按「儲存」，投影頁該座號會消失。
- **哪台裝置用哪組碼**：導師手機用導師碼（記錄、設定都在手機做）；班級電腦用教室碼（只開投影頁與抽籤頁）。
- **投影**：教室電腦開 `board.html` → 按「全螢幕」。最多 5 項作業，在記錄頁的「作業清單」用開關與 ↑ ↓ 調整。
- **發券**：設定頁「發抽籤券」，選座號、張數、原因後送出。
- **抽籤**：教室電腦開 `lottery.html` → 先按「開啟聲音」→ 選座號 → 按「抽」→ 揭曉後按「下一位」。
- **重設籤池**：設定頁輸入「重設」後按按鈕；抽籤紀錄與券異動都會保留。
- **修改籤池或卡片**：直接改試算表的「籤池」「卡片」工作表（例如換實物名稱、調權重、把「啟用」改成「否」）。

## 四、背景音樂

- 預設使用 NCS（NoCopyrightSounds）發行的〈Invisible〉（Julius Dreisig & Zeus X Crona），YouTube 影片 ID `QglaLzo_aPk`，頁尾固定顯示曲名與出處標示。
- 使用範圍以 NCS 官方政策 <https://ncs.io/UsagePolicy> 為準，請導師自行確認。
- `config.js` 的 `MUSIC_SOURCE`：
  - `"youtube"`（預設）：用 YouTube 播放器，藏在畫面外循環播放。
  - `"mp3"`：播放 `assets/lottery-bgm.mp3`。檔案由導師自行取得放入；**若要把 MP3 放在公開的 GitHub Pages，請先自行確認 NCS 政策是否允許公開散布**（`.gitignore` 預設不上傳 mp3）。
  - `"none"`：不播音樂，只用合成音效。
- 學校網路若封鎖 YouTube，畫面會顯示「音樂載入失敗，改用內建音效」，抽籤照常運作。
- 直接雙擊 HTML 檔（`file://` 開啟）時 YouTube 無法嵌入，請用 GitHub Pages 網址開啟。

## 六、實作決定

規格沒寫到的細節，依下列方式處理：

1. **檔案位置**：規格的 `homework-tracker/` 即本資料夾（`Class-Management/`），檔案直接放在根目錄。
2. **getState 的名單**：回傳完整名單並附 `active`（在籍）欄位，記錄頁只顯示在籍座號；設定頁需要不在籍的座號才能切換回在籍。
3. **投影頁不顯示不在籍座號**：轉學或缺號的座號即使有缺交紀錄也不會出現在投影頁。
4. **額外 API**：新增 `ping`（測試存取碼與連線用，只回伺服器時間）；`getLottery` 可帶 `limit`（1 至 50，預設 10），設定頁用 20 筆。`getLottery` 另回傳在籍座號清單、已抽／剩餘數量。
5. **額外錯誤代碼**：程式例外時回 `SERVER_ERROR`（不含錯誤細節）。前端另有 `NETWORK`、`NO_CONFIG`、`BAD_RESPONSE` 等本機錯誤。
6. **draw 的回傳**：除了規格欄位，另附 `seat`（用於「請發給 X 號同學」）與重送時的 `replay: true`。
7. **requestId 保存**：按「抽」時把 requestId 存在瀏覽器；按「下一位」才清除。動畫途中重新整理會提示用同一個 requestId 查回結果。
8. **座號在籍驗證失敗**（`draw`）回 `INVALID_INPUT`；發券給不存在或不在籍座號回 `NOT_FOUND`。
9. **發券規則**：一次 ±1 至 20 張（後端上限 ±50）；「發放」只能正數，「更正」可負數；餘額不得低於 0。
10. **CSV 檢查**：檔案結尾的空白列（Excel 常見）自動忽略，中間的空白列才算錯誤；全形數字自動轉半形；班級代號只接受 10 字以內英數字（避免誤把姓名放進班級代號欄）。列號以 CSV 的列數計算（標題列為第 1 列）。
11. **記錄頁點擊規則**：一般模式點「缺交」會回到原本狀態（原本是已補交就回已補交）；點「已補交」或「正常」變缺交。補交模式只能點紅色座號。已補交的座號以一般樣式顯示，右上角有小字「補」。未儲存的座號有淡橘色外框。
12. **作業修改**：作業清單的「修改」用瀏覽器內建對話框輸入名稱與日期；「刪除」會一併刪除該作業的缺交紀錄。
13. **投影頁字級**：缺交 1 至 10 人時字級 80 至 130 px，11 人以上 64 至 96 px，依空間自動取最大值；作業名稱 56 至 76 px 自動縮放。標題列高 84 px（規格「約 90 px」），讓 30 人排 3 行時仍有餘裕。投影頁標題的日期為「今天」（伺服器時間）。
14. **抽籤動畫時間**：一般模式約 8 至 9 秒（依網路速度略增），縮短模式約 3 秒。撕紙期間音樂維持 10%（讓心跳聲清楚），揭曉時拉回 100%。
15. **按鍵**：抽籤動畫中按 `Esc` 等同「跳過」。
16. **偏好設定**：抽籤頁的音樂、音效、音量、縮短動畫開關記在該裝置瀏覽器。
17. **試算表格式**：日期與時間欄設為純文字格式，避免試算表自動轉成日期；讀取時若遇到日期物件也會自動轉回字串。
18. **權限範圍**：`appsscript.json` 使用 `spreadsheets.currentonly`（比 `spreadsheets` 更小，只能存取綁定的這份試算表）。
19. **YouTube 失敗判定**：腳本載入失敗、15 秒內播放器未就緒、播放器回報錯誤，或點「開啟聲音」後 10 秒仍未開始播放，都視為失敗並改用內建音效。
20. **兩組存取碼（規格原為一組，依導師要求增加）**：新增指令碼屬性 `DISPLAY_CODE`（教室碼），只能呼叫 `ping`、`getBoard`、`getLottery`、`draw`；其他 API 用教室碼呼叫時回新增的錯誤代碼 `FORBIDDEN`，不讀也不改任何資料。`ping` 會回傳目前身分 `role`（`teacher` 或 `display`）。`setup()` 會拒絕兩組相同的存取碼。
21. **暫時登入**：存取碼可選「記住在這台裝置」（瀏覽器 localStorage）或不記住（只存在這個分頁的 sessionStorage，關閉分頁就消失）。暫時登入優先使用，所以班級電腦上導師暫時登入時，教室碼仍保留，登出後投影頁與抽籤頁照常可用。記錄頁、設定頁遇到教室碼時，跳出的導師碼視窗預設**不勾選**記住。

## 七、疑難排解

| Status | Root Cause | Suggested Fix |
| --- | --- | --- |
| 設定頁顯示「尚未設定 GAS 網址」 | `config.js` 的 `GAS_URL` 是空的 | 依步驟 6 貼上 `/exec` 網址 |
| 「伺服器回應格式不正確」 | 網址錯誤，或部署時「誰可以存取」不是「任何人」 | 重新複製部署網址；確認存取權設定 |
| 「存取碼錯誤」 | 輸入錯誤，或指令碼屬性已改 | 到設定頁重新輸入 |
| 記錄頁或設定頁要求輸入導師碼 | 這台裝置登入的是教室碼（設計如此） | 導師要用時輸入導師碼並取消勾選「記住在這台裝置」 |
| 修改 `Code.gs` 後沒有生效 | 沒有部署新版本 | 「管理部署作業 → 編輯 → 新版本 → 部署」 |
| 「系統忙碌中」 | 多台裝置同時寫入超過 10 秒 | 稍等再按一次 |
| 執行 `setup()` 出現「尚未設定導師碼」 | 指令碼屬性沒有 `ACCESS_CODE` | 依步驟 3 新增後再執行 |

**若存取碼外洩**：先到指令碼屬性改掉外洩的那一組（`ACCESS_CODE` 或 `DISPLAY_CODE`，立即止血；教室碼外洩時學生最多只能看投影、用既有的券抽籤）→ 查看 Apps Script「執行項目」紀錄評估影響 → 依校園資安通報流程評估是否需要通報。
